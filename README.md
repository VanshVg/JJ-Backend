# Jay Jalaram Trading Co. – E-commerce Backend

This is the backend API for **Jay Jalaram Trading Co.**, a full-stack grocery e-commerce platform built for a local retail shop. It supports customer and admin functionalities including orders, products, bonus points, payments, and more.

---
## Features

- Authentication (Admin + Customer)
- Product & Inventory Management
- Cart & Order Management
- Bonus Points System
- Payment Support
- Admin Dashboard APIs

---
## Tech Stack

- **Node.js** + **Express.js**
- **PostgreSQL**
- **Sequelize ORM**
- **JWT + Passport** for Authentication
- **Joi** for Validation

---
## Environment Variables

Create a `.env` file in the root directory and configure the following:

```env
PORT=
DATABASE_URL=
LOG_DIR=
```

---
## Installation & Setup

### Clone the repo
``` git clone https://github.com/VanshVg/JJ-Backend.git ```

### Install dependencies
``` npm install ```

### Run in development
``` npm run dev ```

### Run migrations
``` npm run migrations ```
